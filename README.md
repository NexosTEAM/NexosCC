# NexosCC

**Advanced Cooldown Tracking, Aura Management & Interface Customization for World of Warcraft**

NexosCC is a customizable World of Warcraft addon developed by **NexosTEAM**, designed to enhance cooldown visibility, buff and debuff tracking, and combat awareness through a unified interface.

Featuring an extensive **Style Studio**, NexosCC gives players control over cooldown timers, fonts, colors, positioning, and visual behavior.

## Features

### Cooldown Tracking
- Customizable cooldown countdowns on action bars.
- Cooldown displays for supported nameplates and unit frames.
- Duration-based timer colors.
- Custom font sizes, outlines, and text formatting.
- Auto-Fit for improved timer readability.
- Optional final-zero display.

### Style Studio
Customize the appearance of different interface elements independently:

- **Action Bars** — Cooldown text appearance and formatting.
- **Nameplates** — Nameplate cooldown and aura styling.
- **Buffs / Debuffs** — Aura timer customization.
- **Auto-Fit** — Automatic text sizing and layout adjustments.

Choose from multiple fonts, outlines, colors, and duration formatting options.

### Cooldown Ready Alerts
Receive an on-screen notification when an eligible cooldown becomes available.

- Center-screen cooldown completion alerts.
- Configurable minimum cooldown duration.
- Customizable alert positioning and appearance.
- Optional sound notifications.

### Buff & Debuff Tracking
- Player and Target frame aura displays.
- Customizable icon sizes and countdown text.
- Buff and debuff filtering options.
- Nameplate aura tracking.
- Configurable display and positioning.

### Crowd Control Tracking
- Crowd-control indicators for supported units.
- Customizable appearance and positioning.
- Remaining-duration displays where supported by the game client.

### Profiles & Settings
- Create and duplicate configuration profiles.
- Switch between saved profiles.
- Reset or delete supported profiles.
- Persistent settings across game sessions.

## Supported Game Clients

- World of Warcraft Midnight
- World of Warcraft Forever

Some functionality may vary depending on client API availability and interface restrictions.

## Installation

1. Download the latest release from [GitHub Releases](https://github.com/NexosTEAM/NexosCC/releases).
2. Extract the ZIP archive.
3. Copy both addon folders into your World of Warcraft `Interface/AddOns` directory:
   - `NexosCC`
   - `NexosCC_Config`
4. Restart World of Warcraft.
5. Open the NexosCC configuration menu.

## Commands

- `/nexoscc` — Open NexosCC settings.
- `/ncc` — Open NexosCC settings.
